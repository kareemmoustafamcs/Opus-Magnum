## Program 1: Computer Science - 6 Courses

### GitHub Research Project - Extraordinary and Novel - Built from Scratch

**Project Title:** KareemLang: A Complete Systems Programming Language from Scratch

**Project Description:** Design and implement a statically-typed, garbage-collected programming language featuring lexical analysis, recursive-descent parsing, bytecode compilation, and a register-based virtual machine in C. The language supports object-oriented programming, first-class functions, closures, pattern matching, and lightweight concurrency with a custom concurrent garbage collector. Includes a package registry implemented with raw TCP sockets, without external dependencies.

**Core Objectives:**
- Implement lexer, parser, AST, and bytecode VM
- Design type system and garbage collector
- Implement concurrency model
- Build package manager with TCP networking

**Technologies:** C, Assembly, TCP Sockets, Compiler Design

**Complexity and Novelty:** No existing educational language combines OOP, functional, concurrent GC, and custom package registry without libraries. Requires deep understanding of compilers, OS, and networking.
