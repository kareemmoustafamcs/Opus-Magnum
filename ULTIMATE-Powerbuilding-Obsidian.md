## 12-Week Periodization

| Week | Phase | Focus | Load |
| --- | --- | --- | --- |
| 1-3 | Accumulation | Volume | +2.5% weekly |
| 4 | Deload 60% | Recovery | 60% weight, keep skills light |
| 5-7 | Intensification | Reps+ | Add 1 rep per set |
| 8 | Deload 60% | Recovery | |
| 9-11 | Peak | Strength | Test heavy doubles |
| 12 | Test 1RM | Test | Max Bench/Squat/Deadlift/Pull-Up |

> [!TIP] Progressive Overload Rule
> When you hit all sets/reps at RPE <8, add 2.5% weight next session. For skills, add 5 sec per week only.

## Nutrition Calculator - Obsidian Formula

```dataviewjs
// Mifflin-St Jeor - Input your data in properties or here
let weight = 80; // kg
let height = 178; // cm
let age = 24;
let activity = 1.55; // 1.55 = 5-6 days

let bmr = 9.99*weight + 6.25*height - 4.92*age + 5;
let tdee = bmr * activity;
dv.paragraph(`BMR: ${Math.round(bmr)} kcal | TDEE: ${Math.round(tdee)} kcal | Lean Bulk (+10%): ${Math.round(tdee*1.1)} | Bulk (+15%): ${Math.round(tdee*1.15)}`);
dv.paragraph(`Protein 1.6-2.2g/kg: ${Math.round(weight*1.6)}-${Math.round(weight*2.2)}g | Fat 0.8-1g/kg: ${Math.round(weight*0.8)}-${weight}g | Carbs 4-6g/kg: ${weight*4}-${weight*6}g`);
```

**Manual calc if no Dataview:**
- BMR Men = 9.99*weight(kg) + 6.25*height(cm) - 4.92*age +5
- TDEE = BMR x 1.2 sedentary, 1.375 light, 1.55 moderate, 1.725 very active, 1.9 extra
- Target: Lean Bulk TDEE x 1.10, Bulk x 1.15 (5-20% surplus recommended)
- Protein: 1.6g/kg adequate for max lean mass, practical range 1.6-2.2g/kg
- Ideal weight BMI 22-24: low = 22*(height_m^2), high = 24*(height_m^2)
- FFMI = (leanMass / height_m^2) + 6.3*(1.8 - height_m)
